SECTION 2 — TOOL-SPECIFIC SETTINGS
================================================================================

MIDJOURNEY v6 / v7
  Append to the Section-1 prompt:
    --ar 16:9 --style raw --stylize 150 --v 6.1
  Tip: MJ garbles long text. Use Section 4 (Mermaid) for the real labels, and
  use MJ only for a background/hero illustration.

DALL·E 3 (ChatGPT / Bing Image Creator)
  Preface the prompt with: "Create a clean vector-style infographic diagram.
  Render ALL text exactly as written, using correct spelling:"
  Ask for 1792×1024 (landscape). If labels come out wrong, reply:
  "Re-render, fixing the spelling of all labels to match the list exactly."

IDEOGRAM 2.0 / FLUX 1.1 PRO (best for legible text in images)
  Paste Section 1 as-is, 16:9, "Graphic design / infographic" style preset.
  Ideogram handles long in-image text best of all current models.

LEONARDO.AI
  Model: Leonardo Kino XL or Flux Dev · Alchemy OFF · Contrast HIGH ·
  Guidance 6–7 · 16:9.

NEGATIVE PROMPT (where supported)
  photorealistic, 3d render, gradient, drop shadow, neon glow, blurry text,
  misspelled labels, watermark, stock photo, hand-drawn, cluttered,
  cropped boxes, overlapping text.
